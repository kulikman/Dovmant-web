# Shot list

Generated by `npm run shot-list` from `content/images.ts`. Do not edit by hand.

**Framing rule.** No clinical dressing: no gowns, couches, parallel bars, hospital corridors, and nobody being
helped to walk. We photograph a laboratory — markers on the body, force plates, capture cameras, monitors with
traces, cables, hands at a laptop. Participants, not patients. Investigators, not clinicians.

**Priority 1 is shot first.** Those frames carry `/specifications`, which goes live before the rest of the site.

All images are delivered **black & white** (the site applies `grayscale(1)` anyway). Colour comes only from the
accent block added in code. Deliver at least 2× the displayed size — 2400 px on the long edge for hero frames.

File location: `/public/images/<slot-id>.webp` (or `.jpg`), then set `src` in `content/images.ts`.

Until a real file exists each slot shows generated stand-in artwork from `/public/images/art/<slot-id>.svg`
(`npm run art`) — technical line illustrations, there so the layout can be judged. They are placeholders and are
replaced the moment `src` is set.
